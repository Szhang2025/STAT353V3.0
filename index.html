Chapter 1: Foundations of Probability & Discrete Random Variables

1.1 Experiments, Sample Spaces, Events, and Set Operations

An experiment is any procedure with well-defined outcomes. The sample space (\(S\)) is all possible outcomes, and an event (\(E\)) is a subset of \(S\).

  • Union (\(A \cup B\)): Outcomes in \(A\) or \(B\).
  • Intersection (\(A \cap B\)): Outcomes in both \(A\) and \(B\).
  • Complement (\(A^c\)): Outcomes in \(S\) not in \(A\).
  • Disjoint: \(A \cap B = \emptyset\).

1.2 Basic Counting & Probability

$$P(E) = \frac{n(E)}{n(S)}$$

Permutations: \(P_{r}^{n} = \frac{n!}{(n-r)!}\). Combinations: \(\binom{n}{r} = \frac{n!}{r!(n-r)!}\).

1.3 Conditional Probability, Sensitivity, Specificity, Precision, Independence

$$P(A \mid B) = \frac{P(A \cap B)}{P(B)}$$
  • Sensitivity (Recall): \(\frac{TP}{TP + FN}\)
  • Specificity: \(\frac{TN}{TN + FP}\)
  • Precision: \(\frac{TP}{TP + FP}\)
  • Independence: \(P(A \cap B) = P(A)P(B)\)

1.4 Total Probability & Bayes' Rule

$$P(B_j \mid A) = \frac{P(A \mid B_j)P(B_j)}{\sum P(A \mid B_i)P(B_i)}$$

1.5 Random Variables, CDF, PMF, PDF, Expectation, Variance

$$\mu = E[X] = \sum x p(x), \quad V[X] = E[X^2] - (E[X])^2$$

1.6 Joint Distributions & Covariance

Covariance: \(\text{Cov}(X, Y) = E[XY] - E[X]E[Y]\). Correlation: \(\rho_{XY} = \frac{\text{Cov}(X,Y)}{\sigma_X \sigma_Y}\).

Chapter 2: Standard Probability Distributions & Engineering Applications

2.1 Discrete Distributions

  • Binomial: \(P(X=k) = \binom{n}{k}p^k(1-p)^{n-k}\), \(E[X]=np\), \(V[X]=np(1-p)\).
  • Poisson: \(P(X=k) = \frac{e^{-\lambda}\lambda^k}{k!}\), \(E[X]=\lambda\), \(V[X]=\lambda\).
  • Geometric: \(P(X=k) = (1-p)^{k-1}p\), \(E[X]=\frac{1}{p}\).

2.2 Continuous Distributions

  • Uniform: \(f(x) = \frac{1}{b-a}\).
  • Normal: \(Z = \frac{X-\mu}{\sigma} \sim N(0,1)\).
  • Exponential: \(f(x) = \lambda e^{-\lambda x}\), \(E[X]=\frac{1}{\lambda}\). Memoryless property links Poisson process waiting times.
