Chapter 1: Foundations of Probability & Discrete Random Variables

1.1 Experiments, Sample Spaces, Events, and Set Operations

An experiment is any procedure that can be infinitely repeated and has a well-defined set of possible outcomes. The sample space (\(S\)) is the set of all possible outcomes of an experiment. An event (\(E\)) is a subset of the sample space (\(E \subseteq S\)).

  • Union (\(A \cup B\)): Outcomes in \(A\) or \(B\) or both. In reliability engineering, if system success requires subsystem \(A\) or subsystem \(B\) to function, the success event is \(A \cup B\).
  • Intersection (\(A \cap B\)): Outcomes in both \(A\) and \(B\). For instance, in cybersecurity, \(A\) = "packet contains anomaly" and \(B\) = "destination port is restricted".
  • Complement (\(A^c\) or \(A'\)): Outcomes in \(S\) not in \(A\). Represents failure or non-occurrence.
  • Disjoint (Mutually Exclusive) Events: Two events \(A\) and \(B\) are disjoint if \(A \cap B = \emptyset\).
  • Venn Diagrams: Graphical representations used to visualize set intersections, unions, and partitions.

1.2 Basic Counting Methods

When outcomes are equally likely, probability is calculated as:

$$P(E) = \frac{n(E)}{n(S)}$$
  • Multiplication Rule: If an operation can be performed in \(n_1\) ways, and for each way, a second operation can be performed in \(n_2\) ways, the total number of sequences is \(n_1 \times n_2\).
  • Permutations (Order matters): $$P_{r}^{n} = \frac{n!}{(n-r)!}$$
  • Combinations (Order does not matter): $$\binom{n}{r} = \frac{n!}{r!(n-r)!}$$

1.3 Probability Axioms, Conditional Probability, and Independence

Axioms: (1) \(0 \le P(A) \le 1\), (2) \(P(S) = 1\), (3) For mutually exclusive events \(A_1, A_2, \dots\), \(P\left(\bigcup_{i=1}^{\infty} A_i\right) = \sum_{i=1}^{\infty} P(A_i)\).

Conditional Probability:

$$P(A \mid B) = \frac{P(A \cap B)}{P(B)}$$

Diagnostic Metrics in Engineering & Cybersecurity:

  • Sensitivity (Recall / True Positive Rate): \(\text{Sensitivity} = P(\text{Positive Test} \mid \text{Condition Present}) = \frac{TP}{TP + FN}\)
  • Specificity (True Negative Rate): \(\text{Specificity} = P(\text{Negative Test} \mid \text{Condition Absent}) = \frac{TN}{TN + FP}\)
  • Precision (Positive Predictive Value): \(\text{Precision} = P(\text{Condition Present} \mid \text{Positive Test}) = \frac{TP}{TP + FP}\)

Independence: \(A\) and \(B\) are independent if and only if \(P(A \cap B) = P(A)P(B) \iff P(A \mid B) = P(A)\).

1.4 Total Probability and Bayes' Rule

Law of Total Probability: If \(B_1, B_2, \dots, B_k\) partition \(S\):

$$P(A) = \sum_{i=1}^{k} P(A \mid B_i)P(B_i)$$

Bayes' Rule:

$$P(B_j \mid A) = \frac{P(A \mid B_j)P(B_j)}{\sum_{i=1}^{k} P(A \mid B_i)P(B_i)}$$

1.5 Random Variables, CDF, PMF, PDF, and Expectations

  • Random Variable (\(X\)): Measurable function mapping \(S\) to \(\mathbb{R}\).
  • Discrete & PMF: \(p(x) = P(X = x)\), where \(\sum_x p(x) = 1\).
  • Continuous & PDF: \(f(x)\), where \(\int_{-\infty}^{\infty} f(x)\,dx = 1\).
  • Cumulative Distribution Function (CDF): \(F(x) = P(X \le x)\).

Expectation and Variance:

$$\mu = E[X] = \sum_{x} x p(x) \quad (\text{discrete}), \quad \int_{-\infty}^{\infty} x f(x)\,dx \quad (\text{continuous})$$
$$V[X] = E[(X - \mu)^2] = E[X^2] - (E[X])^2, \quad \sigma = \sqrt{V[X]}$$

1.6 Joint Distributions, Covariance, and Correlation

  • Joint PMF: \(p(x, y) = P(X = x, Y = y)\).
  • Covariance: \(\text{Cov}(X, Y) = E[(X - \mu_X)(Y - \mu_Y)] = E[XY] - E[X]E[Y]\)
  • Correlation Coefficient: \(\rho_{XY} = \frac{\text{Cov}(X, Y)}{\sigma_X \sigma_Y}, \quad -1 \le \rho_{XY} \le 1\)

Chapter 2: Standard Probability Distributions & Engineering Applications

2.1 Discrete Distributions

  • Binomial (\(X \sim \text{Bin}(n, p)\)): Models success count in \(n\) independent Bernoulli trials. \(P(X = k) = \binom{n}{k} p^k (1-p)^{n-k}\), \(E[X] = np\), \(V[X] = np(1-p)\).
  • Poisson (\(X \sim \text{Poisson}(\lambda)\)): Models discrete event arrivals in fixed intervals. \(P(X = k) = \frac{e^{-\lambda} \lambda^k}{k!}\), \(E[X] = \lambda\), \(V[X] = \lambda\).
  • Geometric (\(X \sim \text{Geom}(p)\)): Models trial count until first success. \(P(X = k) = (1-p)^{k-1}p\), \(E[X] = \frac{1}{p}\), \(V[X] = \frac{1-p}{p^2}\).

2.2 Continuous Distributions

  • Continuous Uniform (\(X \sim \text{Unif}(a, b)\)): \(f(x) = \frac{1}{b-a}\), \(E[X] = \frac{a+b}{2}\), \(V[X] = \frac{(b-a)^2}{12}\).
  • Normal (Gaussian) (\(X \sim N(\mu, \sigma^2)\)): Bell-shaped symmetric curve. Standardization: \(Z = \frac{X - \mu}{\sigma} \sim N(0, 1)\).
  • Exponential (\(X \sim \text{Exp}(\lambda)\)): Models time between Poisson events. \(f(x) = \lambda e^{-\lambda x}\), \(E[X] = \frac{1}{\lambda}\), \(V[X] = \frac{1}{\lambda^2}\). Possesses the memoryless property.

Chapter 3: Descriptive Statistics & Point Estimation

3.1 The Big Picture of Statistics

Distinguishes between populations (entire collection) and samples (subsets), and parameters (population metrics) versus statistics (sample metrics).

3.2 Numerical and Graphical Summaries

  • Numeric: Mean, median, mode, variance, standard deviation, IQR.
  • Graphical: Histograms (distribution shape), Boxplots (quartiles and outliers), Barplots (categorical frequencies), Scatterplots (bivariate associations).

3.3 Point Estimation & MLE

Maximum Likelihood Estimation (MLE): Maximizes likelihood function \(L(\theta)\) to estimate parameters. Evaluated via bias \(\text{Bias}(\hat{\theta}) = E[\hat{\theta}] - \theta\) and standard error.

Chapter 4: Statistical Inference: Confidence Intervals & Hypothesis Testing

4.1 Sampling Distributions & Central Limit Theorem (CLT)

As sample size \(n\) increases, sampling distributions of sample means \(\bar{X}\) and proportions \(\hat{p}\) approximate normal distributions.

4.2 Inference for Population Proportions

  • Single Proportion CI: \(\hat{p} \pm z_{\alpha/2} \sqrt{\frac{\hat{p}(1-\hat{p})}{n}}\) (Conditions: \(n\hat{p} \ge 10, n(1-\hat{p}) \ge 10\)).
  • Single Proportion Z-test (\(H_0: p = p_0\)): \(z = \frac{\hat{p} - p_0}{\sqrt{\frac{p_0(1-p_0)}{n}}}\).
  • Two Proportions CI: \((\hat{p}_1 - \hat{p}_2) \pm z_{\alpha/2} \sqrt{\frac{\hat{p}_1(1-\hat{p}_1)}{n_1} + \frac{\hat{p}_2(1-\hat{p}_2)}{n_2}}\).
  • Two Proportions Z-test: Uses pooled proportion \(\bar{p}\).

4.3 Inference for Population Means (Welch's Procedures)

  • Single Mean t-Interval: \(\bar{x} \pm t_{\alpha/2, n-1} \frac{s}{\sqrt{n}}\).
  • Single Mean t-Test: \(t = \frac{\bar{x} - \mu_0}{s/\sqrt{n}}\).
  • Two Independent Means (Welch's): Accommodates unequal variances \(\sigma_1^2 \neq \sigma_2^2\) with Welch-Satterthwaite degrees of freedom.

4.4 Sample Size Determination & Error Fundamentals

Margin of error calculations for proportions, sample size formulas, Type I (\(\alpha\)) and Type II (\(\beta\)) errors, significance levels, and correspondence between two-sided CIs and two-tailed tests.

Chapter 5: Categorical Data Analysis & Analysis of Variance (ANOVA)

5.1 Chi-Square Tests

Evaluates categorical associations via Goodness-of-Fit, Homogeneity, and Independence tests: \(\chi^2 = \sum \frac{(O_i - E_i)^2}{E_i}\).

5.2 One-Way ANOVA & Multiple Testing

Compares \(3+\) population means using variance ratios (\(F\)-statistics). Follow-up post-hoc tests (Tukey's HSD) and Bonferroni corrections manage family-wise error inflation.
